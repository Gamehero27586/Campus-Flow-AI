## Color Palette for Campus Flow-AI:-

| Element                           | Colour              | Purpose                       |
| --------------------------------- | ------------------- | ----------------------------- |
| Sidebar and primary navigation    | `#0D4F4C`           | Brand identity                |
| Main background                   | `#FAF7F2`           | Visual breathing room         |
| Primary buttons                   | `#0D4F4C`           | Consistent, prominent actions |
| Secondary actions                 | `#E8735A`           | Distinctive highlights        |
| Reminders and selected indicators | `#F2B84B`           | Draw attention                |
| Cards and content surfaces        | White or warm white | Separate information cleanly  |
| Main text                         | `#2B2B2B`           | Readability                   |

# 60-30-10 rule. 60% of the background/neutral, 30% of the primary, 10% of the accents.

# Design inspiration: Traditional school classrooms, notebook pages, colored chalk, pencils, and colorful textbook covers.

# Design direction: Professional, warm, student-friendly, and recognizable.
